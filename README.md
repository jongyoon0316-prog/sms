# 문자 포워딩 앱 (SmsForward)

휴대폰으로 문자를 받으면 **즉시** 미리 등록한 **2개 번호**로 전달하고, **전달 이력**을 앱 안에 남기는 안드로이드 앱입니다.

## 기능
- 전달받을 번호 2개 등록/저장
- 문자 수신 시 `[발신번호] 본문` 형태로 2개 번호에 각각 전송 (긴 문자는 자동 분할 전송)
- 전달 이력 기록: 시각 / 발신번호 / 전달 대상 / 본문 / 결과(전송중·전송완료·실패 사유)
- 전달 기능 켜기/끄기, 이력 전체 삭제
- 앱이 꺼져 있어도 문자 수신 시 동작 (BroadcastReceiver)

## 빌드 및 설치
1. Android Studio(최신 버전)에서 `SmsForward` 폴더를 **Open**
2. Gradle Sync 완료 후 USB로 연결한 휴대폰(개발자 옵션 + USB 디버깅)에 **Run**
   - 또는 Build > Build APK(s) 로 APK를 만들어 휴대폰에 설치
3. 첫 실행 시 **문자(SMS) 권한** 허용
4. 번호 2개 입력 후 **번호 저장**

## 꼭 확인할 점
- **문자 발송 요금**: 전달 문자는 휴대폰 요금제로 발송됩니다. 문자가 많이 오면 그만큼 발송됩니다.
- **배터리 최적화**: 제조사에 따라 백그라운드 동작이 제한될 수 있으니 설정 > 앱 > 문자 포워딩 > 배터리를 **제한 없음**으로 설정하세요.
- **Play 스토어 배포 불가**: SMS 권한 정책 때문에 스토어 배포는 어렵고, 본인 휴대폰 직접 설치(사이드로딩) 용도입니다.
- **개인정보**: 수신 문자(인증번호 등)가 다른 사람에게 그대로 전달됩니다. 신뢰할 수 있는 번호만 등록하세요.
- 듀얼 SIM 폰은 기본 문자 SIM으로 발송됩니다.

## 구조
- `SmsReceiver.kt` 문자 수신 → 전달 → 이력 기록
- `SentReceiver.kt` 전송 결과(성공/실패) 이력 반영
- `LogDb.kt` 이력 DB(SQLite), `Prefs.kt` 번호/설정 저장
- `MainActivity.kt` 설정 및 이력 화면
